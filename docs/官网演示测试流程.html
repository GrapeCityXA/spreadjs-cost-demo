卡住了先看这里

  • 协同一直连接超时：必须用 http://test.com；确认 Caddy 已启动、后端在改过 LICENSE 后重启过。
  • 填报队列为空：任务可能已提交或已取消；换到“填报人”视角，并确认任务的组织与该账号一致。
  • 责任人下拉为空：该组织下没有持有这个职责的账号；换组织，或先在“组织与用户”分配角色。
  • 报表生成失败：先完成审核定稿；报表模板必须是已发布状态。
  • 一键清理：执行 npm run demo:reset，可分别选择清空字段/组件/模板（默认保留），会先备份并自动重启后端。
