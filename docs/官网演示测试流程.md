# 业务流程走一遍

> 交互记录版：`docs/官网演示测试流程.html`（可勾选、逐条备注，记录保存在浏览器本地）。
> 当前库已预置 7 个业务字段、1 个组件、1 个模板和 1 条填报任务，可直接从 04 协同填报开始；也可以从 01 开始完整重做。
> 协同必须通过 `http://test.com` 访问；localhost 会被域名授权拒绝。

## 00 开始前

1. 启动后端、展示模式前端和 Caddy
   - 后端 3001、展示模式 5199、`http://test.com` 可打开
2. 打开登录页，确认有四个演示视角
   - 设计/管理员、填报人、填报人二、审核/定稿
3. 展示模式不需要服务端报表渲染浏览器
   - 报表在浏览器内生成后上传后端保存；普通模式的后端生成仍需要 `server` 目录执行过 `npx playwright install chromium`

## 01 建业务字段

> 字段是业务口径的字典；模板里的单元格绑定字段，填报数据也按字段存储。

1. 用「设计 / 管理员」进入业务字段目录，确认已有字段
   - 当前有 7 个字段；如果为空，点「新建字段」补充
2. （已有可跳过）确认或新建「重量」：编码 `WEIGHT`，类型 decimal，单位 磅，精度 2，可编辑打开
   - 管理员创建直接生效
3. （已有可跳过）确认或新建「生产日期」：编码 `PROD_DATE`，类型 date，可编辑打开
   - 目录中有两条已批准字段

## 02 做组件和模板

> 组件是表头/表体/表尾的可复用块；模板由组件组合。发布后才能被填报计划引用。

1. 设计模板 → 组件库 → 新建组件
   - 名称如「月报主体」，稳定编码 `monthly_body`，区域 Body
2. 在设计器里打开字段目录，把重量、生产日期拖到单元格；选中单元格 → 单元格属性 → 填报权限，重量单元格的可编辑对象选「填报人一」，生产日期单元格选「填报人二」
   - 单元格出现字段水印，两个单元格分别保存成功；后续由两人分工填写
3. 保存草稿 → 提交发布
   - 管理员提交即发布，组件状态变为已发布
4. 回到模板与组件 → 模板版本 → 从组件组合，选择刚发布的 Body 组件并保存
   - 生成一个模板草稿
5. 打开模板发布检查 → 提交发布
   - 模板版本变为已发布

## 03 发起填报任务

> 填报计划把模板、周期、责任人和期限钉在一起；激活后生成一条填报任务。

1. 填报计划 → 新建填报计划；报告类型自动使用唯一的「月度报告」，只需选择报告期间和刚发布的模板版本
2. 第二步填写截止时间（演示模式不显示组织选择，默认就是当前演示空间）
3. 第三步责任分配：新增两条「填报人」，分别选填报人一和填报人二；提交人选填报人一；审核人和定稿人选审核人
   - 两个填报人都在同一任务里，才能演示真实的双人协同；提交/审核/定稿只能选实际持有对应职责的用户，未分配时不能激活
4. 保存草稿 → 校验配置 → 激活并发起
   - 生成一条填报任务，状态为填报中

## 04 协同填报

> 填报人在协作房间里编辑同一张表；提交后房间冻结，形成不可变的业务修订。

1. 用「填报人一」登录，进入协同填报，打开刚生成的任务
   - 协作状态已连接，重量单元格可编辑
2. 在另一个窗口用「填报人二」登录，打开同一个任务（复制分享链接即可）
   - 两边在线人数都显示 2 人，能看到对方的姓名和选区
3. 填报人一填写重量，填报人二填写生产日期
   - 两人的修改实时同步；各自只能编辑自己负责的单元格
4. 由填报人一（提交人）提交本期数据 → 确认提交
   - 页面变只读，任务状态变为已提交
5. （可选）用同一账号再开一个窗口
   - 也能实时同步，但双账号更能体现真实多人协作

## 05 审核与定稿

> 审核人查看静态提交快照；通过后定稿，生成正式文件和历史版本。

1. 提交后点页面上的「切换为审核人」；或退出登录，用「审核 / 定稿」账号登录，进入审核发布，打开刚提交的任务
   - 显示只读的提交快照，不连接协同房间
2. 填写审核意见，点「通过并保存意见」
   - 任务进入审核中，意见保存
3. 点「生成正式文件并定稿」
   - 任务变为已定稿，历史定稿出现 R1，可下载 XLSX/PDF

## 06 报表输出（可选）

> 报表工作室用已定稿数据生成报表；需要一个已发布的报表模板。只跑业务闭环的话，到定稿已经完整。

1. 报表工作室 → 报表模板 Tab → 新建报表模板，绑定需要的字段并发布
2. 点右上角「生成报表」，选择模板和期间（不需要先切换 Tab）
   - 生成期间页面会锁定，浏览器在屏幕外容器里渲染 ReportSheet；完成后上传后端，切到「生成记录」可预览并下载 Excel / PDF；换同组织范围的账号也能下载

## 卡住了先看这里

- **协同一直连接超时**：必须用 `http://test.com`；确认 Caddy 已启动、后端在改过 LICENSE 后重启过。
- **填报队列为空**：任务可能已提交或已取消；换到"填报人"视角，并确认任务组织与该账号一致。
- **责任人下拉为空**：该组织下没有持有这个职责的账号；换组织，或先在"组织与用户"分配角色。
- **报表生成失败**：先完成审核定稿；报表模板必须是已发布状态。
- **一键清理**：执行 `npm run demo:reset`，可分别选择清空字段/组件/模板（默认保留），会先备份并自动重启后端。
