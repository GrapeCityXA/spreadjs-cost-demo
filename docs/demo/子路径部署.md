# 子路径部署

目标地址：

```text
https://demo.example.com/spreadjs/cost-report/
```

## 构建

```bash
VITE_BASE_PATH=/spreadjs/cost-report/ npm run build:showcase
```

Windows PowerShell：

```powershell
$env:VITE_BASE_PATH = "/spreadjs/cost-report/"
npm run build:showcase
```

也可以把 `VITE_BASE_PATH=/spreadjs/cost-report/` 写进 `.env.showcase`。当前 `.env.showcase` 已默认设置该值，直接执行 `npm run build:showcase` 即可；根路径部署时用 `VITE_BASE_PATH=/` 覆盖。前端构建可用的环境变量都列在该文件里；`SPREADJS_LICENSE`、`DESIGNER_LICENSE` 由 CI 环境变量提供，不要提交真实授权码。仓库不再使用 `LICENSE.js` 文件。

结尾必须有 `/`。代码会根据 `BASE_URL` 自动使用：

```text
/spreadjs/cost-report/assets/...
/spreadjs/cost-report/api/...
/spreadjs/cost-report/collaboration/
```

## 应用层监听子路径

如果上游代理会把 `/spreadjs/cost-report/...` 原样转发给应用、不做前缀重写，就设置后端环境变量：

```bash
APP_BASE_PATH=/spreadjs/cost-report
```

前端构建仍使用 `VITE_BASE_PATH=/spreadjs/cost-report/`，两者必须指向同一个子路径。此时应用自己提供：

```text
/spreadjs/cost-report/           → /spreadjs/cost-report/guide
/spreadjs/cost-report/health
/spreadjs/cost-report/api/...
/spreadjs/cost-report/collaboration/socket.io/...
/spreadjs/cost-report/api/notifications/socket
/spreadjs/cost-report/assets/...
```

代理只需整段转发，`proxy_pass` 必须带上相同的子路径（末尾带 `/`）：

```nginx
location ^~ /spreadjs/cost-report/ {
    proxy_pass http://127.0.0.1:3000/spreadjs/cost-report/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
}
```

这样 `/spreadjs/cost-report/api/...` 会原样转发到后端 `/spreadjs/cost-report/api/...`，后端由 `APP_BASE_PATH` 识别并处理。

不设置 `APP_BASE_PATH` 时应用仍监听根路径，对应下面“代理去掉前缀”的配置方式。两种方式二选一。

## CI 构建

CI 中设置 `APP_BASE_PATH = '/spreadjs/cost-report'`、`VITE_BASE_PATH = '/spreadjs/cost-report/'`，并通过环境变量注入 `SPREADJS_LICENSE`、`DESIGNER_LICENSE`、`SERVER_LICENSE`。构建完成后把 `APP_BASE_PATH` 拼到站点地址后校验 `/health`、`/guide` 和 `index.html` 指纹。

## Nginx

直接监听子路径，不做跳转：

```nginx
server {
    listen 80;
    server_name demo.example.com;
    client_max_body_size 50m;

    location ^~ /spreadjs/cost-report/api/ {
        proxy_pass http://127.0.0.1:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }

    location ^~ /spreadjs/cost-report/collaboration/ {
        proxy_pass http://127.0.0.1:3000/collaboration/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3600s;
        proxy_buffering off;
    }

    location ^~ /spreadjs/cost-report/ {
        alias /srv/cost-report/dist/;
        try_files $uri $uri/ /spreadjs/cost-report/index.html;
        add_header Cache-Control "no-cache";
    }
}
```

## 注意

- 前端授权域名是 `demo.example.com`，路径不影响域名授权；
- 这段配置对应“代理去掉前缀”的方式，后端不需要设置 `APP_BASE_PATH`；
- 如果代理保留前缀，设置 `APP_BASE_PATH` 并使用上一节的整段转发配置；
- 视频地址继续由 `server/config/showcase.json` 配置，可以是绝对 URL；
- 如果资产/CDN 地址使用独立域名，注意 HTTPS 混合内容。
